# Third-party notices

## DOSBox-X

The Windows and Linux packages bundle DOSBox-X `2026.10.01`, from the upstream
release tagged [`dosbox-x-v2026.10.01`](https://github.com/joncampbell123/dosbox-x/releases/tag/dosbox-x-v2026.10.01).
That tag resolves to commit `b6abbd5980a885f5f310a4088c59a8688d1b116c`.
DOSBox-X is a separate program licensed under GNU GPL version 2. Its license
is included with each package as `DOSBox-X-COPYING`. The exact corresponding
DOSBox-X source archive is included in the package as `dosbox-x-source.tar.gz`.
`DOSBox-X-SOURCE.txt` records the source URL and archive SHA-256 for each
package build.

The bundled DOSBox-X files remain under their upstream licenses. This notice
does not place DOSBox-X under the Food Invaders MIT license.
The DOSBox-X source archive preserves the upstream notices for its separately
licensed bundled libraries and components.

## Gameplay reference

The project takes its core arcade idea from Space Invaders. A playable text-mode
reference is [`doctorfree/ninvaders`](https://github.com/doctorfree/ninvaders/tree/dc38ab8db9ecdb5f69fbd3b3deb42e253d6f08c3).
Food Invaders uses its own Assembly implementation and artwork; no source code
from that reference is distributed here.
