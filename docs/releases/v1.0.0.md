# Food Invaders v1.0.0

Food Invaders v1.0.0 is the first maintained public release of the group-built
Assembly game. It packages the existing 16-bit game with DOSBox-X so players
can install and launch it without building the emulator or assembling the
game themselves.

## Downloads

- **Windows x64:** unsigned setup installer with a Start menu shortcut.
- **Fedora 44 x86_64:** RPM package.
- **Ubuntu 24.04 x86_64:** DEB package.
- **Debian 13 x86_64:** DEB package.
- **Source:** the GitHub tag contains the Food Invaders source code and build
  scripts.

Each binary package includes DOSBox-X 2026.10.01, its GPL license, the exact
corresponding source archive, and a source archive checksum. The game source,
art, and project documentation use the MIT license. See
the [third-party notices](https://github.com/Patt-00/Food-Invaders/blob/main/THIRD-PARTY-NOTICES.md)
for the license separation.

## What is included

- Five-stage campaign: Patrol, Flankers, Crossfire, Last Stand, and the
  20-health Ratatouille boss.
- Easy, Normal, and Hard difficulty settings.
- Cleaver and rolling-pin attacks plus temporary speed, damage, and rapid-fire
  power-ups.
- Colored ASCII art rendered in a 180 × 120 DOS text field.
- DOSBox-X normal and dynamic core regression runs in release CI.

## Before you play

Use the keyboard controls shown in the README. The Windows installer is
unsigned. Linux packages target x86_64 and declare the shared-library
dependencies needed by the bundled DOSBox-X build.
