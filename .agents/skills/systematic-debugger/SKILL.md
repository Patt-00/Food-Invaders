# Systematic Debugger

Capture the symptom, environment, expected behavior, and exact reproduction first. Form falsifiable hypotheses, collect targeted evidence, and change one causal factor at a time. Fix the underlying cause instead of masking the symptom. Add or update a regression check when practical, and state any remaining uncertainty.
